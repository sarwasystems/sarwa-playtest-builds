# Sarwa Playtest Builds

Public playtest builds for Sarwa Studios games.

This repository is intended for sharing downloadable test builds with external playtesters, including non-HTML games and prototypes.

Builds may be experimental, incomplete, or unstable. Unless otherwise stated, they are provided for testing and feedback rather than as final releases.

## Playable builds

### NOKIA-MAN — Native R01

Windows x64 native playtest build.

- Open `games/NOKIA-MAN/`
- Read the game-specific `README.md`
- Download `NOKIA-MAN-NATIVE-R01-Windows-x64.zip`
- Extract and run the included `.exe`

## Playtesting

Each game folder should include basic launch instructions, platform requirements, version information, and a place for testers to report feedback or bugs.
