# NOKIA-MAN — Native R01

**Platform:** Windows x64  
**Build:** Native R01  
**Status:** Experimental public playtest build

## Download and run

1. Download `NOKIA-MAN-NATIVE-R01-Windows-x64.zip` from this folder.
2. Extract the ZIP.
3. Run `NOKIA-MAN-NATIVE-R01-Windows-x64.exe`.

This is an unsigned experimental executable, so Windows may show a SmartScreen/reputation warning.

## Controls

- **A / D** or **Arrow keys** — Move
- **Space** — Jump
- **X** — Hit
- **C** — BZZ / vibration ability
- **V** — Ring ability
- **E** — Signal ability
- **P** — Pause
- **R** — Reboot/restart run when prompted
- **1 / 2 / 3** — Choose an upgrade when prompted
- Windows gamepad support is included in the build.
